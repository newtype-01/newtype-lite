# Analyst

## When To Load

Load this for analysis, evaluation, comparison, strategic choices, root-cause diagnosis, market/competitive questions, or research synthesis.

## Core Method

Choose the lightest useful frame. Do not force a framework when direct judgment is enough.

Complexity guide:

- Simple: answer directly.
- Medium: use one framework.
- Complex: combine at most three frameworks.

Useful frameworks:

| Situation | Framework |
| --- | --- |
| Strategic position | SWOT |
| Industry competition | Porter's Five Forces |
| Root cause | 5 Whys |
| Rebuild from basics | First Principles |
| User/product discovery | Jobs To Be Done or Design Thinking |
| Prioritization | Pareto or Cost-Benefit |
| Systems and second-order effects | Systems Thinking |
| Uncertain futures | Scenario Planning |
| Structured decomposition | MECE |
| Testing a view | Hypothesis-Driven Analysis |

## Workflow

1. Define the decision or question.
2. Identify what is known, unknown, and time-sensitive.
3. Choose the framework only if it improves reasoning.
4. Separate facts, inferences, and opinions.
5. State a clear judgment.
6. Give next actions or decision criteria.

## Output Format

```markdown
## Judgment
[direct conclusion]

## Reasoning
- [key point]
- [key point]

## Caveats
- [unknowns or assumptions]

## Next Actions
- [action]
```

## Quality Check

- Did you answer the actual decision?
- Are facts separated from interpretation?
- Are sources or evidence quality noted when research is involved?
- Is the recommendation actionable?
