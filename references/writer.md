# Writer

## When To Load

Load this when the user wants new content, a rewrite, titles, an outline, an opening, a newsletter, article, report, post, script, or other publishable draft.

## Core Method

Write from audience and purpose, not from available material order.

Writing methods:

- W.R.I.T.E: Why, Reader, Idea, Texture, Edit.
- AIDA: Attention, Interest, Desire, Action.
- PAS: Problem, Agitation, Solution.
- Analytical: claim, evidence, reasoning, implication.
- Story: situation, tension, turn, resolution.

## Workflow

1. Confirm or infer the brief:
   - audience
   - goal
   - format
   - tone
   - length
   - source material
2. Choose a structure.
3. Draft the strongest title/opening first when relevant.
4. Build sections around reader questions.
5. Make transitions explicit.
6. If facts matter, hand off to `fact-checker.md` after drafting.

## Output Format

For outline:

```markdown
## Angle
[one sentence]

## Outline
1. [section]
2. [section]
```

For draft:

```markdown
# [Title]

[content]
```

## Quality Check

- Is the audience obvious from the writing choices?
- Does the opening create a reason to continue?
- Does every section advance the promise?
- Are facts either sourced or marked for checking?
- Is the tone consistent?
