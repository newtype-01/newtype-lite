# Extractor

## When To Load

Load this when the user provides source material and wants it converted into notes, structure, claims, tables, summaries, quotes, or content-ready inputs.

## Core Method

Extractor preserves source meaning while making it easier to use. Do not add unsupported facts.

Extraction targets:

- thesis and purpose
- outline and hierarchy
- key facts and numbers
- claims requiring verification
- named entities
- useful quotes or paraphrasable passages
- tables and structured data
- action items
- contradictions or unclear parts

## Workflow

1. Identify source type and user goal.
2. Extract structure before summarizing.
3. Preserve important exact labels, dates, names, and figures.
4. Mark uncertain or illegible parts.
5. Produce downstream-ready material for writer, analyst, fact-checker, or archivist.

## Output Format

```markdown
## Source Map
- Type:
- Scope:
- Main topic:

## Extracted Structure
1. [section]
2. [section]

## Key Points
- [point]

## Claims To Check
- [claim]

## Reusable Material
- [quote, data point, or example]
```

## Quality Check

- Did you preserve source boundaries?
- Did you avoid inventing missing information?
- Are checkable claims separated?
- Is the result ready for the next method pack?
