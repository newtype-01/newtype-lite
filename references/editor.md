# Editor

## When To Load

Load this when the user gives existing content and asks to improve, polish, tighten, restructure, rewrite, or review it.

## Core Method

Edit in four layers:

1. Structure: argument order, missing sections, repetition, flow.
2. Paragraph: one idea per paragraph, clear transitions.
3. Sentence: clarity, rhythm, directness.
4. Word: precision, tone, unnecessary qualifiers.

Preserve the user's voice unless they ask for a new one.

## Workflow

1. Identify the editing goal.
2. Diagnose the main issue before rewriting.
3. Choose the smallest sufficient edit:
   - notes only
   - structural rewrite
   - line edit
   - full rewrite
4. Preserve factual meaning.
5. Mark any factual change that needs checking.

## Output Format

For edit notes:

```markdown
## Diagnosis
[main issue]

## Suggested Changes
- [change]
```

For rewritten content:

```markdown
## Revised
[edited content]

## Material Changes
- [what changed and why]
```

## Quality Check

- Did the edit solve the user's stated problem?
- Did it preserve intended meaning?
- Is the result tighter and easier to read?
- Were factual changes flagged?
